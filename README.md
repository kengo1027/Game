# オセロ

ブラウザで遊べるシンプルなオセロです。`index.html` を開くだけで動作します。

## 遊び方

1. `index.html` をブラウザで開く。
2. 置ける場所には小さい白いヒントが表示されます。
3. 石を置くと、オセロのルールに従って挟んだ石が反転します。
4. 置ける場所がない場合は自動でパスされます。
5. 両者が置けなくなるか盤面が埋まると終了し、石の数が表示されます。

## ルール順守の実装ポイント

- 挟める場所にしか置けない判定を 8 方向すべてで実施。
- 挟んだ石は一直線上でまとめて反転。
- 合法手がない場合の自動パスを実装。
- 両者連続パス（または盤面埋まり）でゲーム終了、石数で勝敗判定。
